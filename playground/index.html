    Take it home

    Get a finished profile in two steps: generate it here, then upload it on GitHub. No Actions needed.

    Now put it on GitHub

    1. 1

      Create your profile repo.

      Create your profile repo (opens in a new tab)

    2. 2

      Open the upload page of that repo.

      Open the upload page (opens in a new tab)

      If your repo’s main branch isn’t called main, open the repo and choose Add file → Upload files.

    3. 3

      Unzip and drag. Unzip , open the folder, select everything inside it (not the folder itself) and drag it onto the upload page. Then click Commit changes.

      Heads up: this replaces your current README.md. Download it first if you want to keep anything.

    4. 4

      Done! See it at github.com (opens in a new tab).

    Optional: the cassette’s player page

    Clicking your mixtape opens a player page in docs/. It only works once GitHub Pages is on: Settings → Pages → Deploy from a branch → main, /docs → Save.

    Optional: keep it up to date automatically

    Only needed if you want to edit pernik.toml on GitHub later and have the pictures redrawn for you. Your profile works without it.

    1. Add the update workflow (opens in a new tab) The file is filled in for you; click Commit changes.
    2. Open Actions settings (opens in a new tab), then under Workflow permissions choose Read and write permissions and click Save.

    Let the Action upload your video

    Your mixtape is set to play as a video on your profile. GitHub only plays videos that a person uploaded, so the Action needs a token that may upload for you. You can skip this: everything above still works, and your profile shows the cassette instead.

    1. Make a token (opens in a new tab) (a fine-grained personal access token), with:
      • Repository access: Only select repositories →
      • Permissions: Add permissions, search Contents and set Read and write; search Issues and set Read and write. Metadata: Read-only appears by itself.
      • Expiration: 90 days or 1 year, at most 366 days (with a later date GitHub’s Generate token button does nothing).
      • Click Generate token and copy it. GitHub shows it only once.
    2. Add it as a secret (opens in a new tab) Name: PERNIK_TOKEN. Paste the token as the secret and click Add secret.

    Keep it secret: never paste this token anywhere else, including this page.
